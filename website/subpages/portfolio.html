KI-Automatisierung · n8n · Firebase

Join Issue Collector

Der Join Issue Collector ist eine Erweiterung meines Join-Projekts. Externe Personen können eine Anfrage vorbereiten und per E-Mail absenden. n8n übernimmt die Nachricht anschließend automatisch, lässt sie von einer KI analysieren und erstellt daraus ein strukturiertes Ticket in Join.

Was passiert automatisch?

Aus einer Anfrage wird ein strukturiertes Join-Ticket.

Der Workflow verarbeitet die tatsächlich gesendete E-Mail und übernimmt nur Informationen, die in der Anfrage enthalten sind. Daraus werden die Felder erzeugt, die Join für ein neues Ticket benötigt.

  • KI erstellt einen passenden Titel und eine sachliche Beschreibung
  • Kategorie wird als Technical Task, User Story oder Bug Request erkannt
  • Priorität wird aus der Anfrage übernommen oder sinnvoll eingeordnet
  • Eine genannte Deadline und ausdrückliche Unterpunkte werden übernommen
  • Das Ticket wird automatisch in Firebase und der Triage von Join angelegt
  • Nach erfolgreicher Verarbeitung erhält der Absender eine Bestätigung per E-Mail
Live ausprobieren

Teste den echten Issue Collector

Du kannst den Ablauf selbst starten. Dafür brauchst du keinen Zugang zum internen Join-Board.

  1. 01
    Issue Collector öffnen

    Wähle auf der Startseite „Create request“, um als Stakeholder eine Testanfrage vorzubereiten.

  2. 02
    Anfrage beschreiben

    Trage Betreff und Beschreibung ein. Optional kannst du auch eine Deadline angeben.

  3. 03
    Mit deinem Webmail senden

    Öffne die vorbereitete Nachricht in Gmail, Outlook oder Yahoo Mail und sende sie ab.

  4. 04
    n8n & KI übernehmen

    Der Workflow verarbeitet die E-Mail, erstellt das Ticket in Join und sendet dir anschließend eine Bestätigung.

Issue Collector starten

Pro Tag können maximal 10 erfolgreich erzeugte Test-Tickets verarbeitet werden. Der Eingang wird von n8n regelmäßig geprüft, daher kann die Verarbeitung einen kurzen Moment dauern.

Der Workflow dahinter E-Mail → n8n → KI-Triage → Firebase → Join → Bestätigung

Der eigentliche n8n-Workflow prüft unter anderem das Tageslimit, validiert die KI-Ausgabe und behandelt auch Fehlerfälle automatisch.
